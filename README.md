# Age of Wars

Welcome to the Age of Wars project! This is an engaging strategy game built using React, TypeScript, and Vite. The game offers two exciting modes: Company Mode and Fight Mode.

## Features

- **Company Mode**: Build and manage your own company, make strategic decisions, and compete with other players.
- **Fight Mode**: Engage in thrilling battles, develop tactics, and outsmart your opponents.
- **Diverse Units and Enemies**: Experience a wide variety of units and challenging bosses that will test your strategic skills.

## Getting Started

To get started with the Age of Wars project, follow these steps:

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/your-username/age-of-wars.git
   cd age-of-wars
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Run the Development Server**:
   ```bash
   npm run dev
   ```

4. **Open the Game**:
   Open your browser and navigate to `http://localhost:3000` to start playing the game.
